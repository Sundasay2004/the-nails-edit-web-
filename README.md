# The Nails Edit – E-commerce Solution

**The Nails Edit** is a modern, responsive web application built to streamline the online shopping experience for nail care products. This project features a custom-built storefront and a functional checkout system, complete with automated transactional email notifications.

## Project Architecture

This project is built using a modern JavaScript development environment powered by **Vite**, ensuring fast builds and optimized production assets.

* **Frontend:** HTML5, CSS3, and JavaScript (`main.js`, `products.js`)
* **Build Tool:** Vite (`vite.config.js`)
* **Pages:**
* `index.html`: Landing and home page.
* `shop.html`: Main product catalog and browsing interface.
* `checkout.html`: Secure checkout and order finalization.



## Key Technical Features

* **Vite-Powered Workflow:** Utilized Vite for rapid development, hot module replacement (HMR), and efficient bundling.
* **Automated Email Integration:** Implemented logic within the checkout flow to trigger instant confirmation emails to customers, ensuring a professional and responsive post-purchase experience.
* **Dynamic Catalog Management:** Data-driven product rendering using `products.js` to manage inventory and display information seamlessly across the shop pages.
* **User-Centric Checkout:** Streamlined order processing through `checkout.html`, focusing on minimal friction and clear communication.

## Getting Started

To run this project locally, ensure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

1. **Clone the repository:**
```bash
git clone [your-repository-link]

```


2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npm run dev

```


4. **Build for production:**
```bash
npm run build

```

By replacing manual order tracking with an automated confirmation system, this platform enhances customer trust and reduces administrative overhead. The architecture is built to be modular, allowing for future integration of payment gateways and advanced inventory tracking systems.
